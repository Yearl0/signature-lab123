# Signature Lab

一个个性签名生成器静态网站 Demo，支持语言选择、MBTI、隐藏名字和哲学名句出处标注。

## 本地预览

直接打开 `index.html` 即可。

## 功能

- 多语言签名生成
- 16 种 MBTI 气质适配
- 藏头、首字母、谐音、意象暗示隐藏名字，并解释名字如何被藏入签名
- 哲学名句灵感与出处标注
- 复制签名卡片
## 生成偏好

- 尽量少用“我”等直白第一人称。
- 优先使用含蓄、留白、半明半暗的表达。
- 避免过度口号化、翻译腔、直白自我定义。
- 哲学灵感偏向改写，不强行堆砌名句。
- MBTI 不只显示在解释里，也会影响签名正文的意象、节奏和词汇。
